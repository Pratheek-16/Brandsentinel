# Task 1: Creator Copy Ingestion & Verified Remediation

## Participant Role: Content Creator (`creator1@novafit.local`)
**Goal:** Ingest a campaign draft, review automated compliance findings, and remediate violations using verified suggestions.

### Instructions
1. Log in to BrandSentinel using the creator credentials.
2. Ensure **NovaFit** workspace is selected.
3. In the Draft Submissions tab, click **"Load sample"** and select **"NovaFit Summer Launch"**.
4. Click **"Run Brand Review"**.
5. When the review screen loads:
   - Identify the flagged banned term `"PulseBand"`.
   - Inspect the Grounded Evidence quote citing the active Knowledge Base rule.
   - Inspect the suggested verified alternative (`"NovaFit Pulse"`).
   - Click **"Accept Fix (v2)"** to remediate.
6. Observe that the canvas refreshes to a clean, compliant version without new regressions.
7. Record the completion timestamp.
