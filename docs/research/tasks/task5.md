# Task 5: Brand Governance Certificate Export & Audit Ledger

## Participant Role: Compliance Auditor / Reviewer
**Goal:** Verify AI utilization ledger metrics and export a tamper-evident Brand Governance Certificate.

### Instructions
1. Open any approved content asset in the **Review & Approvals** tab.
2. Click on the **"AI Usage Ledger"** subtab:
   - Check total characters sent and returned.
   - Check the estimated API cost and prompt version (`v3.1-grounded-judge`).
   - Check the number of masked PII entities.
3. Click the **"Export Certificate"** button in the header action bar.
4. Verify that the downloaded Markdown certificate contains:
   - Unique Certificate ID and issuance timestamp.
   - Content SHA-256 digest matching the text body.
   - Itemized findings ledger with creator resolution notes.
   - SHA-256 digital cryptographic signature.
5. Record completion timestamp.
