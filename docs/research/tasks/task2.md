# Task 2: Multi-Asset Visual & Accessibility Inspection (I-2)

## Participant Role: Marketing Designer / Creator
**Goal:** Inspect visual media and document collateral for WCAG 2.2 AA contrast compliance and alt-text completeness.

### Instructions
1. Navigate to the **"Visual & Contrast (I-2)"** tab in the navigation bar.
2. Select an asset file to audit:
   - Option A: Upload an image banner.
   - Option B: Upload a `.docx` or `.pdf` document.
3. Review the automated analysis output:
   - Check the extracted palette and CIELAB Delta-E distance from approved brand colors.
   - Check the WCAG 2.2 AA contrast ratio (minimum 4.5:1 for body copy).
   - Check the transparent 0-100 Accessibility Score with itemized point deductions.
4. If alt-text is flagged missing (-10 pts), supply a descriptive alt-text label and re-run.
5. Record completion timestamp.
